# As abas

## O que cada aba responde

| Aba | Para que serve |
|---|---|
| CAPA | Entrada do relatório, com o índice das telas |
| VISÃO GERAL | Protocolos por status, equipe, cidade e instalador |
| AGENDAMENTO FIELD | A agenda do campo: turno, base, SLA e produtividade |
| RELATÓRIO DO MÊS | Gerados, realizados, backlog e capacidade do mês |
| RELATÓRIO DO ANO | A série do ano e o total instalado por cidade |
| PREMIAÇÃO INSTALAÇÃO | Apuração por instalador e supervisor |
| DIÁRIO INSTALAÇÃO | O relatório diário de instalações |

## As demais abas

| Aba | Para que serve |
|---|---|
| PROTOCOLOS DETALHADOS | Lista detalhada dos protocolos de instalação FTTx |
| TELEFONIA & OUVIDORIA | Protocolos de telefonia e ouvidoria |
| MANUTENÇÃO INICIAL | Manutenções até 30 dias depois da instalação |
| INSTALAÇÃO / REINCIDENTE | Reincidência por mês, categoria e equipe |
| METAS | Onde a operação edita a meta do mês |
| OPERAÇÃO AO VIVO | O dia acontecendo agora |
| PREVISÕES | O que vem pela frente |

## Trocar de aba

1. Clique no nome da aba na faixa, logo abaixo do título.
2. Se a faixa não mostrar todas, use as setas das pontas para rolar.
3. A aba aberta fica sublinhada.

> **Você só vê as abas liberadas para a sua conta.** Faltou alguma, peça a um administrador do dashboard.

# Problemas comuns

## O que fazer quando aparece

| O que você vê | O que fazer |
|---|---|
| "Sem acesso ao dashboard" | Sua conta entrou, mas não tem aba liberada. Envie o e-mail que a tela mostra a um administrador |
| "Você não tem acesso a esta aba" | A aba existe, mas não é sua. Peça a liberação a um administrador |
| Voltou para a tela de login | A sessão dura 8 horas; também cai se o acesso foi suspenso, venceu ou há afastamento na Senior |
| "Muitas requisições. Tente novamente mais tarde." | Espere o tempo indicado na tela e repita |

## Quando o número parece errado

| Situação | O que fazer |
|---|---|
| Diferente do Power BI | Confira se é o relatório "INST - Relatório Instalação" e se os filtros são os mesmos nos dois lados |
| Diferente na virada do mês | O corte da base usa a data de criação e as medidas somam pela data de instalação: nas pontas, a diferença é esperada |
| Números parados há horas | Fale com o time técnico informando a aba e o horário |
| Um visual com erro | Os outros continuam funcionando; reporte a aba e o nome do visual |

## Ainda não resolveu

1. Anote a aba, os filtros e o período que você estava vendo.
2. Copie o link pelo botão de compartilhar.
3. Mande para intel@sebratel.com.br com o print da tela.

> **Não mande lista de clientes no chamado.** O valor somado e o link já dizem onde olhar.

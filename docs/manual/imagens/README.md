# Prints do manual

Os arquivos abaixo são usados pelos slides (`docs/manual/*.md`). Para trocar um print, salve a
nova imagem **com o mesmo nome** e gere o deck de novo.

| Arquivo | Slide | Situação |
|---|---|---|
| `entrada.png` | Primeiros passos → Primeiro acesso, capa e encerramento | **Pronto** — tela de entrada capturada em 19/11/2026 |
| `tela-completa.png` | Primeiros passos → Conhecendo a tela | **Pendente** — tela inteira logada, com barra superior, faixa de abas, filtros e visuais |
| `filtros.png` | Filtros → Escolher o período | **Pendente** — barra de filtros com a árvore de datas aberta e alguns chips |
| `grafico.png` | Indicadores e gráficos → Ler os gráficos | **Pendente** — um gráfico com paginador visível |
| `tabela.png` | Tabelas e exportação → Trabalhar com a tabela | **Pendente** — tabela de detalhe com o botão de exportar e a paginação |

Os pendentes estão preenchidos com uma imagem de aviso: o deck fica completo, e a troca é só
substituir o arquivo.

## Como capturar

1. Abra o dashboard já logado, na aba e no recorte que o slide descreve.
2. Use um período fechado e, de preferência, uma aba sem nome de cliente à vista.
3. Capture a área indicada em 1600 × 900 ou maior, em PNG.
4. Salve aqui com o nome exato da tabela acima.
5. Gere o deck de novo (veja `docs/manual/gerar-slides.cjs`).

> **Nenhum print pode mostrar dado pessoal de cliente** (nome, telefone, endereço). Prefira telas
> agregadas; se precisar de uma lista, oculte as colunas de identificação antes de capturar.
